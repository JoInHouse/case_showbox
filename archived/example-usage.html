ProcessingButton Component - Usage Examples

1. Basic Usage (Auto-toggle on click)

const button = new ProcessingButton(document.getElementById('basic-button'));

2. Custom Label and Icons

const button = new ProcessingButton(element, {
    label: 'Generate Report',
    defaultIcon: 'img/GenAI.svg',
    endIcon: 'img/Arrow-down.svg'
});

3. Manual Control (No auto-toggle)

const button = new ProcessingButton(element, {
    autoToggle: false
});

// Manual control
button.start();  // Start animation
button.stop();   // Stop animation
button.toggle(); // Toggle state

4. With Event Callbacks

Log: Click the button to see events... 
const button = new ProcessingButton(element, {
    label: 'Process Data',
    onStart: (btn) => {
        console.log('Processing started');
        // Your async operation here
    },
    onStop: (btn) => {
        console.log('Processing stopped');
    }
});

5. Multiple Buttons

// Create multiple independent buttons
const buttons = ['button1', 'button2', 'button3'].map((id, index) => {
    return new ProcessingButton(document.getElementById(id), {
        label: `Task ${index + 1}`
    });
});

6. Programmatic Updates

button.setLabel('New Label');   // Update label
button.isActive();              // Check if processing
button.destroy();               // Cleanup and destroy
